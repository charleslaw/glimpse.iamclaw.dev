A few practical details

Good to know.

Which Macs can run Glimpse?+

Glimpse supports macOS 12 or later. It is a native Mac app built with Swift and AppKit.

Do I need to import my images?+

Open an image directly from its folder. Glimpse lets you browse the neighboring files without importing them into a library or creating an account. You can also make it the default viewer for an image type using Finder’s Open With options.

What happens to my images?+

Glimpse views files locally. It does not collect telemetry or automatically upload images. Optional custom actions can open links or run commands when you select them.

Can I customize the Actions menu?+

The defaults copy an image’s path and reveal its location. You can also configure commands and HTTPS links for your own workflow. See the Actions guide for configuration details.
